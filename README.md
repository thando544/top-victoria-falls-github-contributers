## About this project

This repository automatically indexes GitHub users who **explicitly list Victoria Falls** (or **Vic Falls**) in their profile location field.

It is a living snapshot of the local open-source community — engineers, students, designers, and makers building software from the edges of the Zambezi. The leaderboard is generated by a Python script that queries the GitHub Search API, ranks profiles, and writes the results back into this README.

No manual curation. No gatekeeping. If Victoria Falls is on your GitHub profile, you belong here.

## How to appear on this list

Local developers can join the leaderboard in under a minute:

1. Open your [GitHub profile settings](https://github.com/settings/profile).
2. Find the **Location** field.
3. Set it to one of:
   - `Victoria Falls`
   - `Vic Falls`
4. Optionally add a short **bio** and keep your avatar public — both appear on the table.
5. Wait up to 30 minutes for the next refresh, or run **Update Leaderboard** from the Actions tab.

Contributions are public GitHub activity from the last 12 months (the same total shown on a profile).

Tip: spelling matters. The search looks for an exact location match against those two phrases.
